# Design history

These documents record how mesh-harness was designed:
- the proposal;
- the user journeys;
- the critic analyses;
- the decisions taken with its first owner.

Some of them study one team's own repositories and process as input: their names, spec numbers and figures.

**None of that is a dependency.** Nothing in mesh-harness needs those repositories. The process they describe ships here in generic form:
- the SDD kit (`assets/sdd`, `mesh assets install`);
- the plan templates (`mesh preset ls`).

For using mesh, start with [the guide](../guide/overview.md).
